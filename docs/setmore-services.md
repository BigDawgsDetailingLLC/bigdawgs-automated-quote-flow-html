## Quote-flow → Setmore service mapping

For future auto-booking wire-up: when the quote flow's `submitLead()` fires, it also needs to create a matching Setmore appointment. The `A.finalPkgName` string is what recommend() populates and can key into this catalog.

| A.finalPkgName pattern | Setmore service name |
|---|---|
| `Express Exterior` | Express Exterior |
| `Exterior Decon` | Exterior Decon |
| `Complete Interior` | Complete Interior |
| `Deep Interior Restore` | Deep Interior Restore |
| `Exterior Restore` | Exterior Restore |
| `Standard` | Standard Detail |
| `Signature` | Signature Detail |
| `Elite` | Elite Detail |
| `<name> + Ceramic Coating` | Ceramic Coating — Auto (auto) / Boat — Ceramic Coating (Exterior) (boat) / RV — Ceramic Coating (rv) |
| Any boat E/I combo | Boat — Custom Quoted Appointment (single catch-all) |
| Any RV recommendation | RV — Custom Quoted Appointment (single catch-all) |
| Custom Hand Quote (over-45 boats/RVs, correction paint) | Fleet Consultation (repurpose as generic consult slot) |
